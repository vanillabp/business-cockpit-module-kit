# @vanillabp/bc-module-kit

The module's side of the contract between a
[VanillaBP Business Cockpit](https://github.com/vanillabp/business-cockpit) and a workflow module:
`bc-manifest.json`, the build check `bc-check-entries`, the event protocol, `defineBcElement` and the
names of the entries. Plain JavaScript, no dependencies.

How to use it is in the
[README of the repository](https://github.com/vanillabp/business-cockpit-module-kit#readme).
